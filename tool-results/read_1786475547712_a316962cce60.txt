     1→/**
     2→ * AI Agent catalog — specialized personas for the multi-agent chat.
     3→ *
     4→ * Inspired by the Agency Agents project (https://github.com/msitarzewski/agency-agents)
     5→ * but rewritten with an agriculture focus. Each agent is a system prompt +
     6→ * metadata that shapes the LLM's behavior when the user selects it.
     7→ *
     8→ * Architecture:
     9→ *   - User picks an agent from the catalog
    10→ *   - Frontend sends { agentId, messages } to /api/agronomist-chat
    11→ *   - Backend looks up the agent, prepends its systemPrompt, calls LLM
    12→ *   - Response is shaped by the agent's persona, expertise, and tone
    13→ *
    14→ * Each agent declares:
    15→ *   - id: stable slug for lookup
    16→ *   - name, emoji, color, vibe: visual identity
    17→ *   - description: 1-line summary for the picker card
    18→ *   - systemPrompt: full persona prompt (the bulk of the content)
    19→ *   - sampleQuestions: 3-5 starter prompts to guide the user
    20→ *   - suggestedTools: app tools the agent tends to recommend (for cross-linking)
    21→ *   - category: for grouping in the picker UI
    22→ */
